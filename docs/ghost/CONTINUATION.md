# PROJECT GHOST — CONTINUATION BRIEF

Updated 2026-11-10. Read this first when resuming.

## Where things stand

**Packet Tracer runs headlessly and produces real observations.** Ghost creates a
background-agent copy of the bundle, opens a disposable lab, runs genuine CLI
diagnostics and simple-PDU experiments, and shuts down leaving nothing behind.

**STREAM + VERIFY is at release-candidate quality for the static path.** Answers
stream independently, the verifier contradicts wrong claims, and the buffered
fallback works. The one unmet gate is real-simulator concurrency inside the
browser harness, which needs an authenticated test process.

## The single manual prerequisite

Registration is done on this machine. To redo it elsewhere:

```bash
python -m trident.simulator.registration --install
python -m trident.simulator.registration --verify
```

Registration is per installation and requires the `.pta` to be in
`Contents/extensions`. The `.pta` is generated by the helper using Cisco's own
`meta` tool. No GUI step is needed.

## Decisions not to re-litigate

1. **`--no-gui` alone is not headless.** `fileOpen` activates the app and shows a
   window. `appWindow.setVisible(false)` must run **before** `fileOpen`.
2. **The stock bundle always gets a Dock icon.** The ghost copy sets
   `LSUIElement`; editing its plist invalidates Cisco's signature, so the copy is
   ad-hoc re-signed. The original is never modified.
3. **Launch is opt-in.** `TRIDENT_ALLOW_LIVE_SIMULATOR=1`.
4. **Engine B decodes once.** `open_lab` and the CLI subprocess both re-decode.
5. **SVIs are not shutdown faults.** `Vlan<N>` state follows its member ports.
6. **A ping without a summary is INCONCLUSIVE**, never FAILED.
7. **Only owned processes are terminated**, by PID and process group.
8. **The container is decoded by our own code** (`trident/pktcrypto`), 2.07x
   faster than pkt-core, with pkt-core kept as the fallback for Serpent/CAST.
9. **No `conftest.py` under `tests/browser`.** It shadows the root conftest
   tree-wide. Fixtures live in `tests/browser/browser_fixtures.py`.
10. **The verifier checks a device+address pair before either fact alone.**
    Per-fact checks confirm wrong-device claims.

## Known limitations

- 30 MB container decode is ~108 s (was 215 s). Inherent to pure-Python AES-EAX.
- `provenance.simulator_version` reads `unknown` for the ghost bundle; the real
  version comes from the PTMP handshake.
- Twenty fast static questions appear all at once in the browser: correct
  behaviour, they resolve in ~190 ms.
- Real-simulator concurrency is skipped in the browser suite.
- Verifier covers device existence, address ownership, and the pair. Other claim
  shapes are reported NOT_INDEPENDENTLY_CHECKABLE.
